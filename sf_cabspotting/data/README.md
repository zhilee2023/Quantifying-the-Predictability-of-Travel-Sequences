# Data

- **`sf_dataset.csv`** — Cabspotting / San Francisco taxi trajectory CSV used by `run_sf_experiment.py`.  
  Do not commit large files to git unless you use Git LFS; keep a local copy or download from your institution.

- **`bay_area_counties_ca.geojson`** — Optional. Used by `scripts/bay_area_map_style.py` for map figures; if missing, it is downloaded from the California open data portal (see script).
